#$ DESCRIPTION: VTX power control on the AUX7 switch, taken from "Whoozat" (BetaFPV Air65 65mm whoop) CLI dump of 2026-11-02 (Betaflight 4.5.0).
#$ DESCRIPTION: Each vtx row selects a TX power level for a range of AUX7: the firmware walks the rows in order and the FIRST matching range wins, so the rows must partition the switch travel without overlapping.
#$ DESCRIPTION: Power is a level index into the VTX power ladder (level 0 = 25 mW, 1 = 100, 2 = 200, 3 = 400, 4 = PIT on the factory ladder), and band and channel are left at 0 which means "do not change the current band or channel".
#$ DESCRIPTION: The preset only writes the vtx rows. It does not touch the vtx table, the band table, the power ladder or the selected band, channel and power, so the VTX manufacturer settings are left exactly as configured.
#$ DESCRIPTION: Choose how many power levels the switch steps through. The 3-position option reproduces the captured configuration, which works because rows 3 and 4 in the original dump were unreachable - row 2 covered 1500-2100 and shadowed them.
#$ DESCRIPTION: The 5-position option uses the same five switch segments the original dump implied (900-1150, 1150-1500, 1500-1750, 1750-2000, 2000-2100) with the full factory power ladder.
