#$ DESCRIPTION: VTX TX power control on the AUX7 switch, taken from "Whoozat" (BetaFPV Air65 65mm whoop) CLI dump of 2026-11-02 (Betaflight 4.5.0).
#$ DESCRIPTION: Each vtx row sets the TX power for a range of AUX7. The firmware evaluates the rows on every RX frame and writes the matching row power into vtx_power, so an active row always overrides a power set by hand in the Configurator.
#$ DESCRIPTION: IMPORTANT: at power-up every channel reads midrc (1500) until the radio links, and the rows are evaluated straight away. Any forced row whose range contains 1500 therefore forces its power at every power-up, and that is the value that gets saved - a hand-set power can never survive a reboot. The options are therefore split around 1500: levels are forced on either side of it and only the row that actually contains 1500 is left unmapped.
#$ DESCRIPTION: The range boundaries are in microseconds but the CLI floors them to 25 us steps, and the end of a range is exclusive - so the closest usable boundaries either side of midrc are 1475 and 1525.
#$ DESCRIPTION: The power is an index into the VTX power ladder, which the CLI prints as "vtxtable powerlabels 25 100 200 400 PIT": 1 = 25 mW, 2 = 100 mW, 3 = 200 mW, 4 = 400 mW, and 0 = PIT. A row with power 0 means "leave the power as it is", because the firmware only applies a row power when it is greater than zero - so PIT cannot be selected by a row at all. It can only be set by hand in the Video Transmitter tab.
#$ DESCRIPTION: Band and channel are left at 0, which the firmware reads as "do not change the current band or channel", so this preset touches neither the band table, the power ladder, nor the selected band/channel - the VTX manufacturer settings are left exactly as configured.
#$ DESCRIPTION: The first option leaves the 1500-1750 position unmapped so it holds the power set by hand - the option sets vtx_power = 1, which is 25 mW - while the positions either side of it step 25 / 100 / 200 / 400 mW. The second option has a narrow gap at 1475-1525 instead of an unmapped row, so that position simply keeps whatever power was last set.
#$ DESCRIPTION: The last option reproduces the captured configuration exactly (25 / 100 / 200 / 100 / 200 mW). It is not boot safe: at power-up the 1500 default lands in its 1500-2100 row and forces 200 mW.
