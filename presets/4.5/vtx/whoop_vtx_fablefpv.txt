#$ DESCRIPTION: VTX TX power control on the AUX7 switch, taken from "Whoozat" (BetaFPV Air65 65mm whoop) CLI dump of 2026-11-02 (Betaflight 4.5.0).
#$ DESCRIPTION: Each vtx row sets the TX power for a range of AUX7. The firmware evaluates the rows on every RX frame and writes the matching row power into vtx_power, so an active row always overrides a power set by hand in the Configurator.
#$ DESCRIPTION: IMPORTANT: at power-up every channel reads midrc (1500) until the radio links, and the rows are evaluated straight away. Any forced row whose range contains 1500 therefore forces its power at every power-up, and that is the value that gets saved - a hand-set power can never survive a reboot.
#$ DESCRIPTION: The options are split around that value. Levels below 1500 and levels above it are both possible; only the row that actually contains 1500 has to be left unmapped (power level 0 means "leave the power as it is"). The first option does that with a 1500-1750 manual row, so the mid switch position sits at 25 mW while the positions either side of it step 100 / 200 / 400 / PIT. The second option leaves a narrow gap at 1500 instead of a manual row, so that position simply keeps whatever power was last set.
#$ DESCRIPTION: The remaining options leave one wide manual region (900-1525) and step the power above it. Use them if you want the whole lower half of the switch travel to hold one hand-set power - note that every detent below 1525 then reads the same value.
#$ DESCRIPTION: The firmware only applies a row power when it is greater than zero, so power level 0 (the "25 " level) cannot be selected by a row - it means "leave the power as it is". Power levels 1 to 4 are used for forced positions (1 = 100 mW, 2 = 200, 3 = 400, 4 = PIT).
#$ DESCRIPTION: Band and channel are left at 0, which the firmware reads as "do not change the current band or channel", so this preset touches neither the band table, the power ladder, nor the selected band/channel - the VTX manufacturer settings are left exactly as configured.
#$ DESCRIPTION: The last option reproduces the captured configuration exactly, including its two rows that overlap the 1500-2100 row. It is not boot safe: at power-up the 1500 default lands in that row and forces 400 mW.
